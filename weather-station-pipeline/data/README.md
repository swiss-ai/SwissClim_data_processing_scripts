# Metadata Files

This directory contains essential metadata files required for the data processing pipeline.

## Files

### 1. `meta_info.json` (1.3 MB)
**Source metadata containing station coordinates**

- Format: `{ "station_id": {"latitude": float, "longitude": float}, ... }`
- Contains ~11,800 weather stations worldwide
- Used by `00_build_station_grid_from_metadata.py` to generate grid mapping
- Original coordinates in degrees (lat: -90 to 90, lon: -180 to 180)

**Usage:**
```bash
python scripts/00_build_station_grid_from_metadata.py \
    --input data/meta_info.json \
    --H 90 --W 180 \
    --out_npz data/final_results_station_grid_90x180.npz \
    --out_json data/final_results_mapping_90x180.json
```

---

### 2. `final_results_mapping_90x180.json` (4.3 MB)
**Station-to-grid mapping**

Generated from `meta_info.json` by `00_build_station_grid_from_metadata.py`

- Format: `{ "station_id": {...}, ... }`
- Per-station info:
  - `index`: Unique station index (0-based)
  - `row`, `col`: Grid position in 90×180 grid
  - `lat_orig`, `lon_orig`: Original coordinates
  - `lon_360_orig`: Longitude in [0, 360) range
  - `lat_mapped`, `lon_mapped`: Mapped grid coordinates
  - `dlon_circ`, `dlat`: Mapping errors (degrees)
  - `lat_min`, `lat_max`, `lon_min`, `lon_max`: Grid cell bounds

**Used by:**
- `02_build_station_data_yearly.py` - Maps stations to grid
- `05_select_holdout_stations.py` - Selects validation stations

---

### 3. `final_results_station_grid_90x180.npz` (409 KB)
**Grid coordinates and station information**

Generated from `meta_info.json` by `00_build_station_grid_from_metadata.py`

**Contents:**
- `lon`: [90, 180] Longitude grid (0-360°, strictly increasing along rows)
- `lat`: [90, 180] Latitude grid (-90 to 90°, strictly decreasing along columns)
- `lon_min`, `lon_max`: [90, 180] Cell longitude bounds
- `lat_min`, `lat_max`: [90, 180] Cell latitude bounds
- `station_mask`: [90, 180] Boolean mask (True = has station)
- `station_index_grid`: [90, 180] Station index (-1 if no station)
- `station_id_grid`: [90, 180] Station ID strings ('' if no station)
- `station_ids`: [N] List of all station IDs
- `half`: Grid cell half-width (default: 0.005°)

**Used by:**
- `02_build_station_data_yearly.py` - Provides grid coordinates

---

### 4. `weather_data_norm_stats.json` (1.4 KB)
**Global normalization statistics**

Computed from multi-year data for consistent normalization across all datasets.

**Contents:**
```json
{
  "variables": ["air_pressure", "air_pressure_at_sea_level", ...],
  "locations": [98765.4, 101325.0, ...],  // Per-variable centers
  "scales": [1234.5, 567.8, ...],          // Per-variable scales
  "time_threshold_minutes": 15
}
```

**Variable Mapping:**
- `air_pressure` → `pa` (surface pressure)
- `air_pressure_at_sea_level` → `msl` (sea level pressure)
- `air_temperature` → `2t` (2m temperature)
- `dew_point_temperature` → `dt` (dew point)
- `u_wind` → `10u` (eastward wind)
- `v_wind` → `10v` (northward wind)
- `wind_from_direction` → `wd` (wind direction)
- `wind_speed` → `ws` (wind speed)
- `time_shift` → `ts` (observation time offset)

**Normalization Formula:**
```python
normalized = (raw - location) / scale
raw = normalized * scale + location
```

**Used by:**
- `02_build_station_data_yearly.py` - Stores stats in yearly NPZ files
- All downstream processing - Ensures consistent normalization

---

### 5. `final_holdout_mapping_90x180.json` (429 KB)
**Holdout (validation) station mapping**

Generated by `05_select_holdout_stations.py` using uniform geographic sampling.

- Format: Same as `final_results_mapping_90x180.json`
- Contains 1,000 stations selected for validation
- Uniform geographic distribution (40% minimum coverage)
- Generated with random seed 42 for reproducibility

**Selection Criteria:**
- **Sampling method:** Uniform geographic (equal stations per region)
- **Coverage threshold:** 40% minimum data availability
- **Number of stations:** 1,000
- **Geographic regions:** ~478 clusters
- **Distribution:** 75.6% Northern, 24.4% Southern hemisphere

**Used by:**
- `06_create_holdout_mask.py` - Creates train/holdout masks
- `07_split_dataset_holdout.py` - Splits dataset

## File Dependencies

```
meta_info.json
    ↓ (00_build_station_grid_from_metadata.py)
    ├→ final_results_mapping_90x180.json
    └→ final_results_station_grid_90x180.npz
         ↓ (used in pipeline)
         ├→ 02_build_station_data_yearly.py (uses mapping + grid + norm stats)
         ├→ 05_select_holdout_stations.py (uses mapping)
         │    ↓
         │    └→ final_holdout_mapping_90x180.json
         │         ↓
         │         └→ 06_create_holdout_mask.py
         └→ weather_data_norm_stats.json (used throughout)
```

## Regenerating Metadata

If you need to regenerate the grid mapping (e.g., different grid resolution):

```bash
# Build 90x180 grid
python scripts/00_build_station_grid_from_metadata.py \
    --input data/meta_info.json \
    --H 90 --W 180 --half 0.005 \
    --out_npz data/final_results_station_grid_90x180.npz \
    --out_json data/final_results_mapping_90x180.json

# Or build 180x360 grid (higher resolution)
python scripts/00_build_station_grid_from_metadata.py \
    --input data/meta_info.json \
    --H 180 --W 360 --half 0.0025 \
    --out_npz data/final_results_station_grid_180x360.npz \
    --out_json data/final_results_mapping_180x360.json
```

## Notes

- These files are included in the repository because they are:
  - Small (total ~7 MB)
  - Essential for pipeline operation
  - Time-consuming to regenerate
  - Version-controlled for reproducibility

- The normalization stats (`weather_data_norm_stats.json`) should match across all datasets
- The holdout mapping (`final_holdout_mapping_90x180.json`) ensures consistent train/validation split
- Grid coordinates are stored in 32-bit float precision
- All coordinates satisfy strict monotonicity constraints for proper spatial operations
